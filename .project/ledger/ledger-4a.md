## What this ledger is, and what it fixes

The original Item 7 deleted 222 files under a census that scanned a *worktree*. A deleted file
is not in a worktree, so the census could not see its own deletions: 118 changed paths were
omitted, 100 `migrate` rows were deleted before their replacements existed, 12 paths had no
authority at all, and the gate accepted absence as proof of retirement.

This ledger is derived the other way round. The candidate set comes from a Git **diff**
(`git diff --name-status 1672c57 07531e64`), where deletions are exactly what shows up. Every
path in that set has exactly one row; every row either claims that set or is an explicitly
carried row that must exist at `HEAD`. The checker asserts both directions, and it fails if a
row is dropped, invented, or double-listed.

Every disposition here is *proposed*. Approval is the orchestrator's (rule 11), and the two
CONFLICT rows below are not proposals at all — they are questions.
