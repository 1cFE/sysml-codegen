## Phase 1 — absence seam + corruption authority (D1, M3)

- One tolerant read now lives in `project(result, *, provenance, expects_report)`
  (`projection.py`); `REPORT_CHANNEL` moved there. Both evaluator reads (`evaluator.py:132`, `:203`)
  deleted — one seam, not two.
- Absent channel + `expects_report` False → empty evidence (`responses={}`, `report=None`).
- Absent channel + `expects_report` True → `CorruptConstraintEvidence` (loud, **not** `EvaluationFailed`,
  so it crashes the run instead of committing a healthy-looking case). **M3 authority = the catalog**:
  `study/cli.py` reads `load_model_contract(package_dir).concrete_entries` and passes
  `expects_constraint_report=bool(concrete_entries)`; evaluation stays isolation-clean (a plain bool),
  with a spec-derived default for standalone tests.
- Policy tolerates empty evidence: `DispositionPolicy`/`ObjectivePolicy` return an `unconstrained`
  disposition, resolved **before** the objective/response-role loops (m1).
- **File-backed generalization (in-scope for "both routes"):** `_entry_artifact_path` derives the
  entry file from the spec's single entry binding instead of the hardcoded name — so any generated
  single-group package loads. f1_arithmetic still resolves to `toy_plant_params.json` (suite green).
- GREEN: constraint-free yields empty evidence on **both** routes (`test_constraint_free_*`, INV-A).

## Phase 4 — four statuses + excluded-only (D4, D5)

- **INV-B (excluded-only):** authored `excluded_only` via the real CLI — a non-numerical (boolean)
  constraint predicate that codegen deems ineligible (`concrete: 0, excluded: 1`). Confirms assumption
  **A3 is real**: the aggregator is emitted with `EXPECTED_IDS = ()` → `headline = "not_assessed"`,
  a *present* report with `assessed_count=0`, structurally distinct from constraint-free empty
  evidence (`test_excluded_only_is_not_assessed_distinct_from_constraint_free`). This also validates
  the M3 authority: `bool(concrete_entries)` only gates the *absent*-channel branch, so excluded-only
  (present channel) is never mistaken for corruption.
- **INV-E (four-status exact round-trip + fingerprint):** covered by the existing green composition —
  `test_runner_matrix` (satisfied/violated/indeterminate/not_assessed through the store),
  `test_runner_failures` (assessment_failed preserving evidence, contract 51),
  `test_query::test_every_result_carries_executable_fingerprint` (fingerprint-scoped harvest, never
  merged across fingerprints), and the io round-trip tests — all now exercised on the sealed tree.
- **INV-F (fixture-pinned phase):** `test_both_backends_normalize_native_arithmetic_failure` already
  asserts each arithmetic shape's phase/module against a fixed `EvaluationFailure` record (fixture-
  pinned, not evaluator-agreement) — unchanged and green.
